# GLOBAL ANÚNCIOS GL

Primeira versão inicial (não é ainda uma plataforma publicada).

## Executar
1. Instale Node.js.
2. Copie `.env.example` para `.env`.
3. Preencha a URL e a publishable key do Supabase.
4. Execute `npm install` e `npm run dev`.

A aplicação usa a tabela `public.ads` e o bucket público `ads-images`.
Nunca coloque chaves secretas ou service_role no frontend.
